# Tamara-Portfolio-Website

Portfolio website for Tamara Al-Shobatat, built from the original assets and projects in the Google Drive folder **حقيبة اعمال تمارا**.

## Stack

- React + Vite
- Semantic HTML with Arabic RTL layout
- Responsive CSS with reduced-motion support
- Lazy-loaded visual media
- Interactive project detail modal with embedded HTML experiences and video playback
- SEO metadata in `index.html`

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content source

The portfolio content and media were extracted from the supplied Drive folder. No biographical claims, client details, contact details, or project metrics were added beyond what appears in the source files.
